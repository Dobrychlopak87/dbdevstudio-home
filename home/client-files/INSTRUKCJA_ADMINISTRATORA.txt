PLIKI KLIENTÓW — INSTRUKCJA DLA ADMINISTRATORA

Każdy klient ma osobny katalog o nazwie:

    ID_UŻYTKOWNIKA--ADRES_EMAIL

Przykład:

    u_7a809d4f1e441957--dobry2013chlopak_at_gmail.com

Aby udostępnić plik:
1. Otwórz katalog „client-files” na serwerze.
2. Otwórz katalog właściwego klienta.
3. Wgraj do niego plik przez panel hostingu, FTP lub SFTP.
4. Plik automatycznie pojawi się klientowi w zakładce „Pliki i Faktury”.

Nie trzeba edytować bazy danych ani kodu. Nazwa wyświetlana klientowi jest nazwą
wgranego pliku. Data pochodzi z daty modyfikacji pliku, a rozmiar jest obliczany
automatycznie.

Nowe konto otrzymuje swój katalog automatycznie podczas rejestracji. Jeżeli serwer
nie pozwoli PHP utworzyć katalogu, utwórz go ręcznie według powyższego schematu.

WAŻNE:
- Nie zmieniaj ani nie usuwaj pliku .htaccess w tym katalogu.
- Nie umieszczaj plików klienta w katalogu głównym „client-files”.
- Pliki są pobierane wyłącznie przez chronione API po sprawdzeniu sesji klienta.
- Nie twórz podkatalogów wewnątrz katalogu klienta; lista obsługuje pliki z jednego poziomu.
